# IPAT 법정 기간 암기 퀴즈

지식재산능력시험(IPAT) 대비용 사이트입니다. 특허법·실용신안법, 직무발명(발명진흥법), 디자인보호법, 상표법, 저작권법, 부정경쟁방지법의 날짜와 기간을 정리 노트(간트 타임라인)로 보고, 세 가지 방식의 문제로 외웁니다.

기준: 2026년 11월 14일 시행 법령. 시험 직전에 최신 법령을 한 번 더 확인하세요.

## 모드

| 모드 | 하는 일 |
| --- | --- |
| 정리 노트 | 법별 간트 타임라인을 봅니다. ‘숫자 가리기’를 켜면 굵은 기간을 눌러야 보입니다. 행을 누르면 그 행으로 바로 세 유형 문제를 풉니다. |
| 빈칸 고르기 | 설명 속 굵은 기간이 빈칸이 되고, 빈칸마다 보기 4개 중에서 고릅니다. 숫자키 1~4와 Enter로도 풀 수 있습니다. |
| 숫자 쓰기 | 보기 없이 `3개월`, `1년 6개월`처럼 직접 적습니다. `12개월`과 `1년`처럼 길이가 같으면 정답으로 인정하고, 법 조문 표기를 함께 보여 줍니다. |
| 간트 그리기 | 설명을 읽고 타임라인 위에 기간의 시작 사건과 끝 사건을 끌어서 그립니다. 사건 원 근처에 놓으면 그 사건에 붙고, 채점하면 정답 막대가 겹쳐 보입니다. |
| 섞어서 | 행마다 세 유형 중 하나가 무작위로 나옵니다. |

‘틀린 문제 위주’를 켜면 최근에 틀린 행만 나옵니다. 꺼 두어도 틀린 행일수록 더 자주 나옵니다. 풀이 기록은 브라우저(localStorage)에만 저장됩니다.
