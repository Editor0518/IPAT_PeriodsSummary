# IPAT 법정 기간 암기 퀴즈

지식재산능력시험(IPAT) 대비용 사이트입니다. 특허법·실용신안법, 디자인보호법, 상표법, 저작권법, 부정경쟁방지법의 날짜와 기간을 정리 노트(간트 타임라인)로 보고, 세 가지 방식의 문제로 외웁니다.

기준: 2026년 11월 14일 시행 법령. 시험 직전에 최신 법령을 한 번 더 확인하세요.

## 모드

| 모드 | 하는 일 |
| --- | --- |
| 정리 노트 | 법별 간트 타임라인을 봅니다. ‘숫자 가리기’를 켜면 굵은 기간을 눌러야 보입니다. 행을 누르면 그 행으로 바로 세 유형 문제를 풉니다. |
| 빈칸 고르기 | 설명 속 굵은 기간이 빈칸이 되고, 빈칸마다 보기 4개 중에서 고릅니다. 숫자키 1~4와 Enter로도 풀 수 있습니다. |
| 숫자 쓰기 | 보기 없이 `3개월`, `1년 6개월`처럼 직접 적습니다. `12개월`과 `1년`처럼 길이가 같으면 정답으로 인정하고, 법 조문 표기를 함께 보여 줍니다. |
| 간트 그리기 | 설명을 읽고 타임라인 위에 기간의 시작 사건과 끝 사건을 끌어서 그립니다. 사건 원 근처에 놓으면 그 사건에 붙고, 채점하면 정답 막대가 겹쳐 보입니다. |
| 섞어서 | 행마다 세 유형 중 하나가 무작위로 나옵니다. |

‘틀린 문제 위주’를 켜면 최근에 틀린 행만 나옵니다. 꺼 두어도 틀린 행일수록 더 자주 나옵니다. 풀이 기록은 브라우저(localStorage)에만 저장됩니다.

## 파일 구성

```
index.html      화면 뼈대
css/style.css   스타일 (Pretendard 글꼴, CDN)
js/data.js      정리 노트 데이터 (법 → 차트 → 묶음 → 행)
js/app.js       노트 렌더링 · 문제 출제 · 채점
```

빌드 과정이 없는 정적 사이트입니다. `index.html`을 브라우저로 바로 열거나 아무 정적 서버로 띄우면 됩니다.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

## GitHub Pages로 공개하기

1. 이 리포지토리의 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`로, 브랜치를 `main`, 폴더를 `/ (root)`로 정하고 저장합니다.
3. 잠시 뒤 `https://<사용자명>.github.io/IPAT_PeriodsSummary/` 주소로 열립니다.

## 데이터 고치기

`js/data.js`의 각 행은 이렇게 생겼습니다.

```js
{
  "name": "조약·국내",                       // 행 이름
  "text": "첫 출원일부터 <b>12개월</b> 안에 출원해야 우선권 주장 가능",
  "bars": [{ "s": 2, "e": 3, "k": "h" }],   // 막대: 시작·끝 사건 번호(소수 가능), 무늬
  "cmt": ["≠ 디자인 6개월"]                 // 다른 법과 비교 (채점 후 표시)
}
```

- `<b>…</b>`로 감싼 값이 빈칸 고르기와 숫자 쓰기의 빈칸이 됩니다.
- `s`, `e`는 차트의 `ms`(사건) 배열 순번입니다. 사건과 사건 사이는 소수로 적습니다.
- 무늬 `k`: `h` 빗금(핵심 기간), `o` 땡땡이(보충 기간), `l` 옅은 막대(유지 기간), `d` 점선(늦게라도 가능), `g` 생존 기간, `s` 글자가 든 막대, `p` 점.
- 간트 그리기는 행의 대표 막대(빗금 우선, 그다음 긴 막대)로 채점하며, 시작과 끝 모두 사건 간격의 ±0.35 안이면 정답입니다.
- `[[nw:…]]`는 신설·개정 배지, `[[fu:…]]`는 시행 예정 배지로 표시됩니다.
